# Application icon

Original AI-generated artwork created with OpenAI's built-in image generation on
2026-11-07 for Hollow Mac Trainer. Two ivory masks represent the Knight and Hornet;
a vermilion silk loop connects them on a graphite macOS tile. No community artwork
was copied into the asset. This is an unofficial fan utility, not a Team Cherry icon.

Visual references: [community Silksong icons](https://www.steamgriddb.com/game/1043/icons),
[official Silksong art](https://hollowknightsilksong.com/), and
[Apple icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons).
The references informed the strong mask silhouette, restrained palette, and readable
small-size composition.

`app-icon.png` is the original transparent master. `app-icon.icns` contains the
standard 16–1024 pixel representations. Rebuild it on macOS with
`python3 tools/build_icon.py`; the application build also runs this step.

Generation direction: two distinct overlapping ivory porcelain masks, Knight in
the left foreground and taller Hornet on the right; one vermilion silk ribbon with
an infinity-like loop; graphite rounded-square tile; shallow satin relief; clean
silhouettes and subtle top-left lighting; no text, ornaments, particles, or scenery.
